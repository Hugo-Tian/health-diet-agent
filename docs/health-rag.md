# 饮食健康知识库 RAG v2

2026-10-21：8个主题、16个片段、9个官方页面。新增片段当天核对，旧片段保留2026-10-20核对日期。中文整理未经临床专业审查；原文审阅日期与本地核对日期分开保存，不称为最新临床指南。

## 内容

消化性溃疡（饮食、警示症状）、胃食管反流（进餐时间、个人诱因）、便秘（纤维、液体）、乳糖不耐受（耐受、营养替代）、腹泻（恢复饮食、症状记录）、肠易激综合征（纤维、低FODMAP）、胃炎（病因、营养吸收）、DASH血压饮食教育（搭配、份数）。

每个片段的原文链接、短摘录、章节和日期均保存在`backend/data/health_guidance.json`。来源机构为NIH旗下NIDDK和NHLBI；知识是患者教育整理，不是个体治疗指南。`limits`是本项目应用约束，不全是原文翻译。

## 检索实现

1. LangChain `HealthGuidanceRetriever`读取JSON，检查HTTPS、完整域名和路径白名单、必填元数据与日期。到期片段不参与检索。
2. Unicode规范化，英文词及中文双字切分。别名命中，或整理问法至少3个词重合且覆盖率不低于0.6，才进入候选。英文词边界避免ribs误命中IBS。
3. BM25内容排序与别名/整理问法覆盖排序，用RRF（k=60）融合。优先保留不同主题，最多6条。
4. 明确指代的追问（如“刚才这种情况”）从最近一条用户问题解析主题。不把模型历史回答当证据，不跨账号、不将健康记录写入索引。
5. DeepSeek可使用自动检索上下文或search_health_guidance工具。最终引用必须来自本轮实际检索；结构格式和引用分别有一次修正机会，持续失败回滚草案。

这是两路词法检索，没有部署Embedding模型、向量数据库、交叉编码器或Ragas依赖。整理问法改善已覆盖表达，不能保证任意同义句召回，分数不是医学置信度。[GitHub参考与取舍](rag-references.md)。

## 浏览和评测

助手页展开“浏览饮食知识库与检索示例”，查看全部片段或试搜。只读接口GET /api/v1/knowledge?q=...要求登录，不调用模型、不改计划。过期片段仍可浏览，但会标记且不参与回答检索。

从backend目录执行：

```powershell
..\.venv\Scripts\python.exe -m app.evaluate_rag
..\.venv\Scripts\python.exe -m pytest -q
```

评测集backend/data/rag_eval.json有32条整理用例，覆盖口语、复合主题及不应命中的问题。32/32通过、期望片段Recall@6为1.0、负例拒绝率1.0仅代表该回归集；部分问法与检索样例重合，不是独立盲测或医疗正确率。引用存在性检查不能证明每个模型结论均有原文支持，语义忠实性及临床审查仍待完善。

## 维护与边界

新增资料须核对官方原文，保存片段级publisher、verified_on、review_due和review_status；更新版本、增加正反例、运行测试并重启服务。整理问法只作检索辅助，不是医学事实。复核期限2027-04-20，到期停用，不代表已安排自动更新。

资料解释原则，食物库提供营养，计划工具创建待确认卡片。检索命中不是确诊，也不是食物对某疾病适用性的认证。FODMAP、实际用盐或治疗目标数据不足时不能宣称菜单达标。现有危险症状规则是窄范围提示，不是完整分诊系统。运行时不抓取第三方网页。
